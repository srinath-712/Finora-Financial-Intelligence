Build a polished, production-quality Gen-Z financial intelligence web application UI.

This is a frontend prototype only. Do not build a real backend, authentication, real trading, live APIs, or production database. Use realistic mock data and local state.

PRODUCT

The product combines two concepts:

FINORA — PERSONAL FINANCE

The user can manage and understand their personal finances:

Dashboard

Transactions

Accounts

Budgets

Goals

Recurring expenses

Investments

Reports

Financial insights

AI financial assistant

QUANTAGENTS-NSE — INVESTMENT INTELLIGENCE

The user can analyze Indian stocks and understand their portfolio:

Stock analysis

Technical indicators

News sentiment

Fundamental analysis

BUY / HOLD / SELL analysis

Multi-agent investment opinions

Portfolio performance

Market insights

The final application should feel like one unified financial product, not two applications stitched together.
